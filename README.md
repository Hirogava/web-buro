# Travel Guide

Это простой шаблон сайта-путеводителя на **чистом HTML и CSS** для использования в 5-дневном курсе веб-разработки.

## 📁 Структура проекта

```
travel_guide_template/
├── index.html          # Главная страница
├── about.html          # Страница "О месте"
├── gallery.html        # Галерея фотографий
├── festivals.html      # Фестивали и события
├── contact.html        # Контакты и форма
├── css/
│   ├── style.css       # Основные стили
│   └── pages.css       # Стили для отдельных страниц
├── images/             # Папка для фотографий
└── README.md           # Описание проекта
```

## Что нужно сделать
1. Выбрать город или страну
2. Заполнить все страницы контентом
3. Добавить минимум 10 фотографий
4. Изменить цвета сайта
5. Проверить, что все ссылки работают

## Страницы
- Главная — краткое описание и достопримечательности
- О месте — история и факты
- Галерея — фотографии
- Контакты — форма


#### 1. Измените название сайта
В файле `index.html` найдите:
```html
<div class="logo">Travel Guide</div>
```
И замените на название вашего города/страны.

#### 2. Обновите содержимое
- **index.html**: Измените заголовок, описание и названия достопримечательностей
- **about.html**: Напишите подробное описание города/страны
- **gallery.html**: Добавьте названия для фотографий
- **contact.html**: Обновите контактную информацию

#### 3. Добавьте фотографии
1. Сохраните фотографии в папку `images/`
2. В HTML файлах замените пути на фотографии:
   - `images/placeholder1.jpg` → `images/ваша-фотография.jpg`
   - `images/gallery1.jpg` → `images/фото1.jpg`

#### 4. Измените цвета (опционально)
В файле `css/style.css` найдите цвета:
```css
background-color: #0066cc;  /* Синий цвет */
```

Замените на нужные вам цвета. Примеры кодов цветов:
- `#FF5733` - красный
- `#00AA00` - зелёный
- `#FFAA00` - оранжевый
- `#AA00FF` - фиолетовый

## 🖼️ Как добавить фотографии

1. Найдите хорошие фотографии в интернете (например, на Unsplash.com)
2. Сохраните их в папку `images/`
3. В HTML файлах обновите пути:

```html
<!-- Было -->
<img src="images/placeholder1.jpg" alt="Фото">

<!-- Стало -->
<img src="images/eiffel-tower.jpg" alt="Эйфелева башня">
```

## ❓ Часто задаваемые вопросы

**Q: Как изменить цвет кнопок?**
A: В файле `css/style.css` найдите `.btn-primary` и измените `background-color`.

**Q: Как сделать текст больше?**
A: В CSS найдите `font-size` и измените значение (например, с `18px` на `24px`).

**Q: Как добавить новую страницу?**
A: Создайте новый HTML файл, скопируйте структуру из `index.html` и добавьте ссылку в меню.

**Q: Почему фотографии не показываются?**
A: Проверьте, что:
1. Фотография находится в папке `images/`
2. Путь в HTML правильный (например, `images/photo.jpg`)
3. Расширение файла правильное (`.jpg`, `.png` и т.д.)
